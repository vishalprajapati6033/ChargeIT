# ⚡ ChargeIT

An interactive web application designed to optimize and streamline EV (Electric Vehicle) charging station discovery and route planning. Built with a focus on core software engineering principles, ChargeIT eliminates range anxiety by providing real-time tracking, seamless navigation, and intuitive user interfaces.

🌐 **[Live Demo](https://vishalprajapati6033.github.io/ChargeIT/)**

---

## 🚀 Key Features

- **Interactive Map & Navigation:** Seamlessly plot paths to the nearest available charging stations.
- **Station Discovery:** View live locations, socket types, and availability statuses of EV charging hubs.
- **Rigorous Software Architecture:** Developed using structured systems analysis, featuring comprehensive Data Flow Diagrams (DFDs) and system models.
- **Responsive Web Design:** Fully optimized for fluid performance on both mobile and desktop viewports.

---

## 🛠️ Tech Stack

- **Frontend:** JavaScript (ES6+), HTML5, CSS3
- **Deployment & Hosting:** GitHub Pages
- **System Design & Modeling:** Structured Data Flow Frameworks (DFDs Level 0, 1, 2)
