# DFD Level-1

### **Entities:**
1. **Admin**: Manages users and station information.
2. **User**: Registers, logs in, searches for stations, and makes bookings.
3. **Station Owner**: Manages station details and views bookings.
### **Processes:**
1. **User Registration and Login**: The user provides an ID and password for authentication.
2. **Find and Book Stations**: The user searches for available charging stations and requests to book a slot.
3. **Manage Stations**: The station owner updates station information and views the booking list.
4. **Manage Users**: The admin manages user information and handles booking confirmations or cancellations.
5. **View Bookings and Cancellations**: Users and station owners can view booking statuses and cancellations.
### **Data Stores:**
1. **User Information Database**: Stores user profiles and login credentials.
2. **Booking Database**: Stores booking requests and confirmations.
3. **Station Information Database**: Stores station details.
### **Data Flow:**
- The **User** sends login credentials to access the system.
- The **User** searches for stations and requests bookings.
- The **Admin** handles user management and confirms/cancels bookings.
- The **Station Owner** manages station data and views booking details.
- The system sends booking confirmations or cancellations to the user.
- All data is stored in the respective databases.
