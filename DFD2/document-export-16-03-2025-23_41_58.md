# DFD Level-2

### **1. Admin Panel:**
- **View Booking List**: Admin can view all the bookings made by users.
- **Generate Reports**: Admin can generate reports based on user activity and station data.
- **Manage User Data**: Admin manages user profiles and their credentials.
- **Manage Station Details**: Admin can add, update, and delete station information.
### **2. User Management System:**
- **User Registration**: New users can register on the platform.
- **Profile Management**: Users can update their personal information.
- **User Authentication**: Handles login/logout functionality.
### **3. Station Management System:**
- **View Station Availability**: Users can check the availability of charging slots.
- **Add or Update Station Information**: Station owners can add or modify station details.
- **Manage Charging Slots**: Owners can manage charging slots and their status.
### **4. Booking Management System:**
- **View Booking History**: Users can view their past bookings.
- **Search for Stations**: Users can search for nearby charging stations.
- **Book Charging Slots**: Users can book available slots.
- **Cancel Bookings**: Users can cancel their bookings.
- **Get Booking Confirmation**: Confirmation message after successful booking.
### **5. Databases:**
- **User Database**: Stores user credentials and profile details.
- **Station Database**: Stores station details and charging slot data.
- **Booking Database**: Stores booking details and history.
---

### **Data Flow:**
- Users, Admin, and Station Owners interact with the system through different modules.
- All data flows are connected to the respective databases for storing and retrieving information.
